# Guides

These guides provide task-oriented instructions. Start with the
[Tutorial](../tutorials/index.md) if the terminology is unfamiliar.

- [Installing](setup/installing.md): the base install, and which extra provides each
  capability.
- [Authoring configurations](setup/configuration.md): composing reusable fragments,
  profiles, overlays, and command line overrides into one validated run.
- [Packaging plugins](extending/plugins.md): publishing runtime and declaration roles
  through installed metadata.
- [Instrumenting an external model](probes/external-model-site-maps.md): declaring,
  observing, and patching sites in a third-party Torch model.
- [Running sweeps](experiments/sweeps.md): expanding, pricing, and launching experiment
  points locally or through a site profile.
- [Judgment corpora](judgments/judgment-corpora.md): the data root layout and design
  documents the corpus-backed judgment designs read.
- [Running the law suites](extending/laws.md): checking an implementation you wrote
  against the laws the protocol it implements is required to satisfy.
- [The debug checks](extending/checks.md): what `LOFI_CHECK` enables and when to use it.
